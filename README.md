# ARMO Ordini

Programma desktop per richieste di offerta, offerte cliente, documenti e produzione.

## Download e aggiornamenti

Scaricare il Setup dalla sezione Releases. Dalla versione 1.1.0 è disponibile anche **Impostazioni > Controlla aggiornamenti** nel programma.
Il controllo degli aggiornamenti utilizza questo repository e cerca un file denominato `ARMO-Ordini-Setup-VERSIONE.exe` nella release stabile più recente.

## Versione 1.1.0

- Importi PDF completi entro i margini.
- Excel esportabile senza fornitore e senza invio email.
- Scelta tra salvataggio Excel e preparazione di una bozza email.
- Ricarico indipendente per ogni voce, percentuale oppure euro per unità.
- Aggiornamenti con controllo versione, download verificato e backup prima del Setup.

I dati degli ordini e i documenti aziendali restano nell'archivio configurato sul PC e non sono inclusi nei download.
